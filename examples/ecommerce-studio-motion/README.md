# Studio motion and detail template

Legacy template example: existing compiled copies remain usable. Before compiling a new version, inspect the source and add `shots[].direction` as described in [the direction contract](../../docs/guide/ecommerce-direction.md). Do not infer source evidence from the old prompt alone.

Three source shots over 8.433 seconds: front movement, angle-to-front presentation, then one structure gesture plus surface detail. Music only; no dialogue or mandatory captions. The underlying logic is reusable across products via focus/action adaptation slots.

The source video, screenshots, song, and finished local bundle are not committed. Upgrade and compile `analysis.json` against a local reference video, then add a real product reference before planning. `product.example.json` describes only the original trousers; it is not a claim about a new product. Grok basic generates at least 6 seconds per shot (18 seconds for three tasks), then reviewed trims produce the shorter edit.
