# Studio motion and detail template

Three source shots over 8.433 seconds: front movement, angle-to-front presentation, then one structure gesture plus surface detail. Music only; no dialogue or mandatory captions. The underlying logic is reusable across products via focus/action adaptation slots.

The source video, screenshots, song, and finished local bundle are not committed. Compile `analysis.json` against a local reference video, then add a real product reference before planning. `product.example.json` describes only the original trousers; it is not a claim about a new product. Grok basic generates at least 6 seconds per shot (18 seconds for three tasks), then reviewed trims produce the shorter edit.
