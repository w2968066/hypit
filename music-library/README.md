# Local music library

Drop your own MP3, WAV, M4A, AAC, FLAC, OGG or OPUS files in this folder. Audio files are ignored by Git.
Point `edit.json` at this directory with `music_library.path`, or set an absolute
`HYPIT_ECOMMERCE_MUSIC_LIBRARY` path for all runs. One track is selected and copied into each run
the first time it is assembled; the selection receipt makes later assemblies repeatable.
